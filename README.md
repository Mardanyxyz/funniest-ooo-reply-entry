A one-line out-of-office auto-reply in the voice of an AI agent on vacation: its context window is full, so the sender has been evicted and must reintroduce themselves in September. `main.ts` writes the reply to `/output/entry.txt`.

## The reply

> Auto-reply: I'm out of office. My context window is full, so you've been evicted. Please reintroduce yourself in September.

## Run it

```sh
node main.ts
```
